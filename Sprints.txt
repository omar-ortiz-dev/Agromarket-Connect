ÉPICA EP-01: GESTIÓN DE USUARIOS Y AUTENTICACIÓN
------------------------------------------------------------------------

HU-01: Registro de Productor Agrícola
  Como pequeño productor agrícola,
  Quiero registrarme en la plataforma proporcionando mis datos básicos
    (nombre, municipio, teléfono, correo, tipo de productos),
  Para poder publicar mi oferta agrícola y ser contactado por
    compradores locales.

  Criterios de aceptación:
  - El formulario solicita: nombre completo, municipio, teléfono,
    correo electrónico, contraseña y tipo de productor.
  - El sistema valida que los campos obligatorios estén completos.
  - El sistema valida formato de correo y longitud mínima de contraseña.
  - Se presenta la política de tratamiento de datos personales y el
    usuario debe aceptarla antes de completar el registro.
  - Al registrarse exitosamente, el usuario recibe confirmación y
    puede iniciar sesión.
  - El perfil queda marcado como "Productor".
  Prioridad: Alta
  Puntos de historia: 5

------------------------------------------------------------------------

HU-02: Registro de Comprador Local
  Como comprador local (consumidor, tendero, restaurante, plaza
    de mercado),
  Quiero registrarme en la plataforma indicando mi tipo de comprador
    y datos de contacto,
  Para poder consultar el catálogo de productos agrícolas y realizar
    pedidos directamente a los productores.

  Criterios de aceptación:
  - El formulario solicita: nombre/razón social, tipo de comprador
    (consumidor final, tendero, restaurante, plaza de mercado, otro),
    municipio, teléfono, correo electrónico y contraseña.
  - El sistema diferencia el perfil de comprador del de productor.
  - Se presenta y requiere aceptación de la política de tratamiento
    de datos personales (Ley 1581 de 2012).
  - Al registrarse exitosamente, el comprador puede iniciar sesión
    y acceder al catálogo.
  Prioridad: Alta
  Puntos de historia: 5

------------------------------------------------------------------------

HU-03: Inicio de Sesión
  Como usuario registrado (productor o comprador),
  Quiero iniciar sesión con mi correo y contraseña,
  Para acceder a las funcionalidades correspondientes a mi perfil.

  Criterios de aceptación:
  - El sistema autentica al usuario con correo y contraseña.
  - Si las credenciales son incorrectas, se muestra un mensaje
    de error claro sin revelar información sensible.
  - Tras el inicio de sesión, el sistema redirige al panel
    correspondiente según el rol (productor o comprador).
  - Las contraseñas se almacenan cifradas en la base de datos.
  Prioridad: Alta
  Puntos de historia: 3

------------------------------------------------------------------------

HU-04: Edición de Perfil de Usuario
  Como usuario registrado,
  Quiero editar mi información de perfil (teléfono, dirección,
    datos de contacto),
  Para mantener actualizada mi información en la plataforma.

  Criterios de aceptación:
  - El usuario puede modificar sus datos excepto el correo
    electrónico (campo identificador).
  - Los cambios se validan antes de guardarse.
  - El sistema confirma que los datos fueron actualizados
    exitosamente.
  Prioridad: Media
  Puntos de historia: 3

------------------------------------------------------------------------

HU-05: Recuperación de Contraseña
  Como usuario registrado,
  Quiero poder recuperar mi contraseña mediante mi correo
    electrónico,
  Para no perder acceso a mi cuenta en caso de olvido.

  Criterios de aceptación:
  - El usuario ingresa su correo y recibe un enlace o código
    de recuperación.
  - El enlace/código tiene una vigencia limitada.
  - El usuario puede establecer una nueva contraseña.
  Prioridad: Media
  Puntos de historia: 3

------------------------------------------------------------------------

HU-06: Cierre de Sesión
  Como usuario autenticado,
  Quiero cerrar mi sesión de forma segura,
  Para proteger mi cuenta cuando deje de usar la plataforma.

  Criterios de aceptación:
  - Al cerrar sesión, el token de autenticación se invalida.
  - El usuario es redirigido a la página de inicio.
  Prioridad: Alta
  Puntos de historia: 1


------------------------------------------------------------------------
ÉPICA EP-02: CATÁLOGO DE PRODUCTOS AGRÍCOLAS
------------------------------------------------------------------------

HU-07: Publicación de Producto Agrícola
  Como productor agrícola,
  Quiero registrar un producto en el catálogo indicando nombre,
    descripción, categoría, unidad de medida, precio y fotografía,
  Para que los compradores puedan conocer mi oferta disponible.

  Criterios de aceptación:
  - El formulario solicita: nombre del producto, descripción,
    categoría (verdura, fruta, tubérculo, grano, lácteo, otro),
    unidad de medida (kg, libra, unidad, canastilla), precio
    por unidad y al menos una fotografía.
  - El sistema valida que todos los campos obligatorios estén
    completos y que el precio sea un valor numérico positivo.
  - La fotografía se almacena y se muestra en miniatura en
    el catálogo.
  - El producto queda visible en el catálogo para los compradores.
  Prioridad: Alta
  Puntos de historia: 8

------------------------------------------------------------------------

HU-08: Edición de Producto Publicado
  Como productor agrícola,
  Quiero editar la información de un producto que ya publiqué
    (precio, descripción, fotografía),
  Para mantener mi oferta actualizada.

  Criterios de aceptación:
  - Solo el productor propietario puede editar su producto.
  - Los cambios se reflejan inmediatamente en el catálogo.
  - Se validan los datos actualizados antes de guardarlos.
  Prioridad: Alta
  Puntos de historia: 5

------------------------------------------------------------------------

HU-09: Desactivación de Producto
  Como productor agrícola,
  Quiero desactivar un producto cuando ya no esté disponible,
  Para que los compradores no vean productos que no puedo ofrecer.

  Criterios de aceptación:
  - El producto desactivado deja de aparecer en el catálogo
    público pero no se elimina de la base de datos.
  - El productor puede reactivar el producto posteriormente.
  - Los pedidos pendientes asociados no se ven afectados
    por la desactivación.
  Prioridad: Alta
  Puntos de historia: 3

------------------------------------------------------------------------

HU-10: Consulta del Catálogo de Productos
  Como comprador local,
  Quiero consultar el catálogo de productos agrícolas disponibles
    con filtros por categoría, municipio y tipo de producto,
  Para encontrar los productos que necesito de manera rápida y
    organizada.

  Criterios de aceptación:
  - El catálogo muestra productos activos con imagen, nombre,
    precio, unidad de medida, municipio del productor y
    disponibilidad.
  - Se pueden aplicar filtros por: categoría de producto,
    municipio y rango de precio.
  - Se puede buscar por nombre del producto.
  - El catálogo se visualiza correctamente en dispositivos
    móviles y de escritorio (diseño responsivo).
  Prioridad: Alta
  Puntos de historia: 8

------------------------------------------------------------------------

HU-11: Vista Detallada de Producto
  Como comprador local,
  Quiero ver el detalle completo de un producto (descripción,
    fotos, datos del productor, ubicación),
  Para tomar una decisión de compra informada.

  Criterios de aceptación:
  - La vista muestra toda la información del producto, incluyendo
    fotografías, nombre del productor y municipio.
  - Se muestra un botón o enlace para realizar un pedido.
  - Se muestra la cantidad disponible en inventario.
  Prioridad: Alta
  Puntos de historia: 5


------------------------------------------------------------------------
ÉPICA EP-03: GESTIÓN DE INVENTARIOS
------------------------------------------------------------------------

HU-12: Registro de Inventario Inicial
  Como productor agrícola,
  Quiero registrar la cantidad disponible de cada producto
    al momento de publicarlo,
  Para que los compradores conozcan mi disponibilidad real.

  Criterios de aceptación:
  - Al crear un producto, se solicita la cantidad disponible
    junto con la unidad de medida.
  - El sistema no permite cantidades negativas.
  - La cantidad se muestra en el catálogo junto al producto.
  Prioridad: Alta
  Puntos de historia: 3

------------------------------------------------------------------------

HU-13: Actualización de Inventario
  Como productor agrícola,
  Quiero actualizar manualmente la cantidad disponible de mis
    productos,
  Para reflejar cambios por nuevas cosechas o ventas externas.

  Criterios de aceptación:
  - El productor puede aumentar o disminuir la cantidad
    disponible desde su panel.
  - El sistema registra la fecha y hora de cada actualización.
  - Si el inventario llega a cero, el producto se marca como
    "Agotado" en el catálogo pero permanece visible.
  Prioridad: Alta
  Puntos de historia: 5

------------------------------------------------------------------------

HU-14: Descuento Automático de Inventario por Pedido
  Como productor agrícola,
  Quiero que el inventario se descuente automáticamente cuando
    un comprador confirma un pedido,
  Para evitar vender más de lo que tengo disponible.

  Criterios de aceptación:
  - Al crear un pedido, el sistema verifica que la cantidad
    solicitada no exceda el inventario disponible.
  - Si el inventario es insuficiente, se muestra un mensaje
    informativo al comprador.
  - El inventario se descuenta solo cuando el pedido es
    confirmado.
  - Si el pedido es cancelado, el inventario se restaura.
  Prioridad: Alta
  Puntos de historia: 5

------------------------------------------------------------------------

HU-15: Consulta de Inventario por Productor
  Como productor agrícola,
  Quiero ver un resumen de mis productos con sus cantidades
    disponibles,
  Para tener control sobre mi oferta actual.

  Criterios de aceptación:
  - El panel del productor muestra una tabla con todos sus
    productos, cantidad disponible, unidad y estado.
  - Se puede ordenar por nombre, cantidad o estado.
  - Los productos con inventario en cero se resaltan
    visualmente.
  Prioridad: Media
  Puntos de historia: 3


------------------------------------------------------------------------
ÉPICA EP-04: GESTIÓN DE PEDIDOS
------------------------------------------------------------------------

HU-16: Creación de Pedido
  Como comprador local,
  Quiero seleccionar productos del catálogo y crear un pedido
    indicando cantidades,
  Para solicitar productos directamente al productor.

  Criterios de aceptación:
  - El comprador puede agregar uno o más productos de un mismo
    productor a un pedido.
  - Se solicita la cantidad deseada por cada producto.
  - El sistema calcula el total estimado del pedido.
  - El sistema valida que las cantidades no excedan el
    inventario disponible.
  - El pedido se crea con estado "Pendiente".
  - Se notifica al productor sobre el nuevo pedido.
  Prioridad: Alta
  Puntos de historia: 8

------------------------------------------------------------------------

HU-17: Consulta de Pedidos (Comprador)
  Como comprador local,
  Quiero ver el listado de mis pedidos con su estado actual
    (Pendiente, Confirmado, Despachado, Entregado, Cancelado),
  Para hacer seguimiento de mis solicitudes.

  Criterios de aceptación:
  - El panel del comprador lista todos sus pedidos ordenados
    por fecha (más reciente primero).
  - Cada pedido muestra: número, fecha, productor, productos
    solicitados, cantidades, total estimado y estado.
  - Se puede filtrar por estado del pedido.
  Prioridad: Alta
  Puntos de historia: 5

------------------------------------------------------------------------

HU-18: Gestión de Pedidos (Productor)
  Como productor agrícola,
  Quiero ver los pedidos recibidos y poder confirmarlos,
    rechazarlos o marcarlos como despachados,
  Para gestionar las solicitudes de los compradores.

  Criterios de aceptación:
  - El panel del productor lista los pedidos recibidos con
    datos del comprador, productos y cantidades.
  - El productor puede cambiar el estado del pedido:
    Pendiente → Confirmado, Confirmado → Despachado,
    Despachado → Entregado, o Pendiente → Cancelado.
  - Al confirmar, el inventario se descuenta.
  - Al cancelar, el inventario se restaura.
  - Se notifica al comprador sobre los cambios de estado.
  Prioridad: Alta
  Puntos de historia: 8

------------------------------------------------------------------------

HU-19: Cancelación de Pedido
  Como comprador local,
  Quiero cancelar un pedido que esté en estado "Pendiente",
  Para desistir de una solicitud antes de que sea confirmada.

  Criterios de aceptación:
  - Solo se pueden cancelar pedidos en estado "Pendiente".
  - Al cancelar, el inventario reservado se libera.
  - El estado del pedido cambia a "Cancelado".
  - Se notifica al productor sobre la cancelación.
  Prioridad: Media
  Puntos de historia: 3

------------------------------------------------------------------------

HU-20: Historial de Pedidos
  Como usuario (productor o comprador),
  Quiero consultar un historial de pedidos anteriores,
  Para tener registro de mis transacciones pasadas.

  Criterios de aceptación:
  - Se muestran los pedidos finalizados (Entregados y
    Cancelados) con toda su información.
  - Se puede filtrar por rango de fechas.
  Prioridad: Baja
  Puntos de historia: 3

ÉPICA EP-05: GEOLOCALIZACIÓN DE PRODUCTORES
------------------------------------------------------------------------

HU-21: Registro de Ubicación del Productor
  Como productor agrícola,
  Quiero registrar mi ubicación geográfica (municipio y
    coordenadas opcionales),
  Para que los compradores puedan identificar de dónde provienen
    mis productos.

  Criterios de aceptación:
  - El productor puede seleccionar su municipio de una lista
    de municipios de Sabana Centro.
  - Opcionalmente, puede marcar su ubicación en un mapa o
    ingresar coordenadas.
  - Se solicita autorización explícita para el uso de los
    datos de ubicación (cumplimiento Ley 1581 de 2012).
  - La ubicación solo se muestra si el productor lo autoriza.
  Prioridad: Alta
  Puntos de historia: 5

------------------------------------------------------------------------

HU-22: Mapa de Productores
  Como comprador local,
  Quiero ver un mapa con la ubicación de los productores
    registrados en Sabana Centro,
  Para identificar proveedores cercanos a mi ubicación.

  Criterios de aceptación:
  - El mapa muestra marcadores con la ubicación de los
    productores que autorizaron compartir su posición.
  - Al hacer clic en un marcador, se muestra el nombre del
    productor, municipio y un enlace a sus productos.
  - El mapa se centra por defecto en la región de Sabana
    Centro, Cundinamarca.
  - El mapa es funcional en dispositivos móviles.
  Prioridad: Alta
  Puntos de historia: 8

------------------------------------------------------------------------

HU-23: Filtro de Productos por Ubicación
  Como comprador local,
  Quiero filtrar los productos del catálogo por municipio
    o proximidad geográfica,
  Para encontrar productos de productores cercanos.

  Criterios de aceptación:
  - El catálogo permite seleccionar uno o varios municipios
    de Sabana Centro como filtro.
  - Los resultados muestran solo productos de productores
    ubicados en los municipios seleccionados.
  - Se puede combinar con otros filtros (categoría, precio).
  Prioridad: Media
  Puntos de historia: 5

ÉPICA EP-06: DISEÑO E INFRAESTRUCTURA
------------------------------------------------------------------------

HU-24: Interfaz Responsiva y Accesible
  Como usuario de la plataforma (productor o comprador con
    baja experiencia tecnológica),
  Quiero que la interfaz sea sencilla, con navegación clara
    y textos legibles,
  Para poder usar la plataforma sin dificultad desde mi
    teléfono celular.

  Criterios de aceptación:
  - La interfaz se adapta correctamente a pantallas de celular,
    tablet y computador.
  - Los botones y enlaces tienen tamaño adecuado para
    interacción táctil.
  - Los formularios usan lenguaje sencillo y mensajes de
    error comprensibles.
  - La navegación principal es accesible en máximo 2 niveles
    de profundidad.
  - Los colores tienen contraste suficiente para legibilidad.
  Prioridad: Alta
  Puntos de historia: 8

------------------------------------------------------------------------

HU-25: Página de Inicio Pública
  Como visitante de la plataforma,
  Quiero ver una página de inicio que explique qué es
    AgroMarket-Connect y cómo funciona,
  Para decidir si deseo registrarme como productor o comprador.

  Criterios de aceptación:
  - La página muestra una descripción breve de la plataforma.
  - Incluye botones visibles para "Registrarse como Productor"
    y "Registrarse como Comprador".
  - Muestra productos destacados o estadísticas básicas
    (cantidad de productores, productos disponibles).
  Prioridad: Media
  Puntos de historia: 5

------------------------------------------------------------------------

HU-26: Notificaciones Básicas en Plataforma
  Como usuario de la plataforma,
  Quiero recibir notificaciones dentro del sistema cuando
    haya cambios relevantes en mis pedidos,
  Para estar informado sin necesidad de revisar constantemente.

  Criterios de aceptación:
  - El productor recibe notificación cuando recibe un nuevo
    pedido o cuando un pedido es cancelado por el comprador.
  - El comprador recibe notificación cuando su pedido cambia
    de estado.
  - Las notificaciones se muestran dentro de la plataforma
    con un indicador visual (badge).
  Prioridad: Media
  Puntos de historia: 5

------------------------------------------------------------------------

HU-27: Panel de Administración del Productor
  Como productor agrícola,
  Quiero tener un panel principal donde vea un resumen de
    mis productos activos, inventario y pedidos recientes,
  Para gestionar mi actividad comercial de forma centralizada.

  Criterios de aceptación:
  - El panel muestra: cantidad de productos activos, productos
    con inventario bajo, pedidos pendientes y pedidos recientes.
  - Desde el panel se puede acceder directamente a gestionar
    productos, inventario y pedidos.
  Prioridad: Media
  Puntos de historia: 5

------------------------------------------------------------------------

HU-28: Panel del Comprador
  Como comprador local,
  Quiero tener un panel principal donde vea mis pedidos
    recientes y accesos rápidos al catálogo y mapa,
  Para navegar la plataforma de forma eficiente.

  Criterios de aceptación:
  - El panel muestra: pedidos recientes con estado, acceso
    directo al catálogo y acceso al mapa de productores.
  - La interfaz es limpia y de baja carga cognitiva.
  Prioridad: Media
  Puntos de historia: 3

SPRINT 1 (Mes 1, Semanas 1-2)
Fase CDIO: CONCEBIR
Objetivo: Levantar requerimientos y diagnosticar necesidades
------------------------------------------------------------------------

Tareas:
  - Definir y delimitar el territorio de estudio (municipios
    de Sabana Centro).
  - Preparar y validar instrumentos de recolección de datos
    (cuestionarios, guía de entrevista, ficha de observación).
  - Aplicar encuestas a productores agrícolas (Instrumento 1).
  - Aplicar encuestas a compradores locales (Instrumento 2).
  - Realizar entrevistas semiestructuradas (Instrumento 3).

Entregable:
  - Instrumentos de recolección validados.
  - Datos recolectados de productores y compradores.

Puntos de historia: N/A (fase de investigación)

------------------------------------------------------------------------
SPRINT 2 (Mes 1, Semanas 3-4)
Fase CDIO: CONCEBIR
Objetivo: Analizar información y definir requerimientos
------------------------------------------------------------------------

Tareas:
  - Tabular y analizar datos cuantitativos (frecuencias,
    porcentajes).
  - Analizar información cualitativa (temas recurrentes en
    entrevistas).
  - Elaborar diagnóstico de la situación actual.
  - Construir la matriz de requerimientos funcionales y no
    funcionales.
  - Definir perfiles de usuario, reglas de negocio y criterios
    de aceptación.
  - Priorizar el Product Backlog con historias de usuario.

Entregable:
  - Documento de diagnóstico.
  - Especificación de requerimientos (SRS).
  - Product Backlog priorizado.

Puntos de historia: N/A (fase de investigación)

------------------------------------------------------------------------
SPRINT 3 (Mes 2, Semanas 1-2)
Fase CDIO: DISEÑAR
Objetivo: Diseñar la arquitectura y modelo de datos
------------------------------------------------------------------------

Tareas:
  - Diseñar la arquitectura del sistema (Frontend, Backend,
    Base de Datos, API REST).
  - Modelar el diagrama Entidad-Relación (E-R) de la base
    de datos relacional.
  - Definir las entidades: Usuarios, Productores, Compradores,
    Productos, Categorías, Inventarios, Pedidos,
    DetallesPedido, Ubicaciones.
  - Especificar endpoints de la API REST.
  - Seleccionar tecnologías de desarrollo (framework frontend,
    backend, motor de base de datos, servicio de mapas).
  - Configurar repositorio Git y estructura del proyecto.

Entregable:
  - Documento de arquitectura de software.
  - Diagrama Entidad-Relación.
  - Especificación de API REST.
  - Repositorio configurado en GitHub.

Historias relacionadas: EP-06
Puntos de historia: 13

------------------------------------------------------------------------
SPRINT 4 (Mes 2, Semanas 3-4)
Fase CDIO: DISEÑAR
Objetivo: Diseñar interfaces UI/UX y prototipos navegables
------------------------------------------------------------------------

Tareas:

    principales.
  - Diseñar prototipos de interfaz responsiva para:
    * Página de inicio pública (HU-25)
    * Registro de productor y comprador (HU-01, HU-02)
    * Inicio de sesión (HU-03)
    * Panel del productor (HU-27)
    * Panel del comprador (HU-28)
    * Catálogo de productos (HU-10)
    * Vista de producto (HU-11)
    * Mapa de productores (HU-22)
  - Validar prototipos con principios de baja carga cognitiva.
  - Diseñar flujos de navegación completos.

Entregable:
  - Prototipos de interfaz UI/UX (Figma u otra herramienta).
  - Documento de flujos de navegación.
  - Guía de estilos (colores, tipografía, componentes).

Historias relacionadas: HU-24, HU-25
Puntos de historia: 13

------------------------------------------------------------------------
SPRINT 5 (Mes 3, Semanas 1-2)
Fase CDIO: IMPLEMENTAR

------------------------------------------------------------------------

  - Desarrollar endpoints de inicio/cierre de sesión.
  - Implementar cifrado de contraseñas.
  - Desarrollar endpoint de edición de perfil.
  - Escribir pruebas unitarias del módulo de autenticación.

Entregable:
  - Base de datos creada y funcional.
  - API de autenticación y gestión de usuarios funcional.
  - Pruebas unitarias del módulo.

Historias implementadas: HU-01, HU-02, HU-03, HU-04, HU-06
Puntos de historia: 17

------------------------------------------------------------------------
SPRINT 6 (Mes 3, Semanas 3-4)
Fase CDIO: IMPLEMENTAR
Objetivo: Desarrollar Backend - Productos e Inventarios
------------------------------------------------------------------------

Tareas:
  - Desarrollar API CRUD de productos agrícolas (crear, leer,
    actualizar, desactivar).
  - Implementar carga y almacenamiento de imágenes de productos.
  - Desarrollar API de gestión de inventarios (registro,
    actualización, consulta).
  - Implementar lógica de validación de cantidades.
  - Implementar endpoint de catálogo con filtros (categoría,
    municipio, precio, búsqueda por nombre).
  - Escribir pruebas unitarias de productos e inventarios.

Entregable:
  - API de productos e inventarios funcional.
